# Hermes Android 界面视觉系统

## 视觉定位

Hermes Android 是高频使用的个人工作终端。界面优先保证内容清晰、操作直接和长时间阅读舒适，品牌色与圆角层次只用于建立重点，不用于填满页面。

## 两套皮肤

### 清爽办公

- 页面背景使用中性浅灰或深灰。
- 内容面板使用实体表面，不使用装饰阴影和亮边。
- 列表优先平铺，只有需要表达分组关系时才使用面板。
- 底部导航贴合系统导航区域，不使用悬浮外框。

### 圆润卡片

- 环境背景可保留低饱和蓝、紫、暖色光晕，但所有内容表面保持不透明。
- 顶栏、底栏、输入器、弹层和重点面板使用实体圆角表面、柔和阴影和清晰描边，不使用顶部反光或透明叠层。
- 文档正文、文件列表和长文本区域优先平铺，避免圆角面板过度嵌套。

## 尺寸规则

| 项目 | 规格 |
| --- | --- |
| 页面左右边距 | 16 dp |
| 高密度内容边距 | 12 dp |
| 控件圆角 | 8–10 dp |
| 普通面板圆角 | 12–16 dp |
| 弹层与悬浮 Dock 圆角 | 24 dp |
| 最小操作触控区域 | 48 dp，紧凑工具栏不低于 44 dp |
| 页面标题 | 20 sp / 27 sp |
| 行标题 | 16 sp / 23 sp |
| 正文 | 14–15.5 sp / 21–23 sp；Markdown 正文使用紧凑档 |
| 辅助文字 | 12.5 sp / 18 sp |

主页面补充规则：固定身份或导航区域应与可滚动内容分离；分段栏在页面级视图切换时占满内容宽度，紧凑只调整高度与字号；同一组统计和操作优先合并到一个连续面板中，避免孤立在页面角落。

## 色彩层级

- 主色：主要按钮、当前选项和品牌状态。
- 辅助色：AI、模型及次要选中状态。
- 成功色：网关在线、任务完成和有效状态。
- 警告色：生成中、等待和需要注意的状态。
- 错误色：失败、删除和不可逆操作。
- 页面不得直接新增浅色专用色值；新增业务颜色必须同时定义浅色与深色语义角色。

## 页面层级

1. 页面标题和当前状态。
2. 当前页面的主要操作或主要内容。
3. 可浏览的列表、设置与辅助操作。
4. 解释性文字、版本信息和低频入口。

同一屏幕不同时使用多个渐变按钮、多个彩色统计卡和多个悬浮面板。只有当前最重要的操作使用主色实心按钮。

## 图标使用边界

v0.6.4.1 统一使用 Hermes Light 图标系统。79 枚图标全部基于 24 × 24 网格，采用轻量圆角几何与克制的蓝、青、绿、紫、黄、红语义色；返回、关闭、发送、编辑、状态和拖动条等系统操作也使用同一套资源。Android 端使用日/夜双套 PNG 位图保证真机兼容和深色模式识别度，SVG 母版继续作为可维护设计源；页面不得重新引入 Material 默认图标或硬编码浅色专用图标颜色。

Switch、Checkbox 和进度指示器继续使用 Material 交互控件，以保留完整触控、禁用态和无障碍语义；它们不作为装饰图标处理。
